# AI Image Upscaler

A professional AI-powered image upscaling tool that helps users enhance and enlarge images while maintaining clarity and detail.

## Features

* AI-powered image upscaling
* Improve image resolution and clarity
* Simple and easy-to-use interface
* Fast image processing
* Clean and modern design
* Supports common image formats

## Run Locally

### Prerequisites

* Node.js
* npm

### Installation

1. Clone this repository:

```bash
git clone https://github.com/graphicsexpert65-png/ai-image-upscaler.git
```

2. Open the project folder:

```bash
cd ai-image-upscaler
```

3. Install dependencies:

```bash
npm install
```

4. Add your API key to `.env.local` if required:

```env
GEMINI_API_KEY=your_api_key_here
```

5. Start the development server:

```bash
npm run dev
```

The app will run locally in your browser.

## Build for Production

```bash
npm run build
```
